开心宠物相机 · 技术支持

更新及生效日期：2026年10月9日

开心宠物相机为 iPhone 和 iPad 提供宠物拍摄辅助、拍照、录像、实况、屏幕补光和视频提帧。以下说明按当前项目功能更新；较旧安装版本可能没有全部入口。主要功能在本机完成，无需应用账号。

一、拍摄与智能出片

基本拍摄、倒计时和对焦怎么使用？

拍摄页可切换拍照、录像和实况。倒计时支持3、5、10秒；照片模式还可使用30秒连拍。录像前可选择设备支持的 HD / 4K 与帧率，开始录制后无法更改。

普通取景可轻点重新对焦，长按可对焦并锁定；录像中轻点可对焦并锁定。在一键出片中点按识别到的宠物可锁定主角并自动缩放，再点取景画面可解除。

如何使用“宠物一键出片”？

打开拍摄页的“智能出片”，选择“宠物一键出片”。应用会切换到后置拍照并持续寻找合适时机自动抓拍；可在同一菜单暂停、继续或关闭。多只宠物同框时，可点按识别框选择主角。

保持设备稳定，让猫狗在充足光线下清晰入镜。宠物太小、移动过快、遮挡、对焦未稳或光线不足都可能影响抓拍；不会保证每个动作都拍到。

如何从新录制的视频提取照片？

在“智能出片”选择“录像提取照片”，会切换到录像并开始录制，点击拍摄键结束。应用保留原视频，并在本机挑选精彩照片保存到系统相册；通常目标约8张，实际数量取决于内容和设备状态。它更适合奔跑或动作较多的宠物。

提帧需要时间，进入后台后能否继续由系统决定；重新打开应用可恢复未完成任务。电量、发热或存储不足也可能影响处理，请先查看页面提示及待保存作品。

如何从相册里已有的视频提取照片？

  1. 在“智能出片”选择“导入视频提取照片”，通过系统选择器选择一个视频。
  2. 设置分析区间，使用智能推荐，或通过时间轴、逐帧调整手动挑选瞬间。
  3. 点击候选照片放大查看，勾选后保存到系统相册。

单次智能推荐分析区间最多5分钟，较长视频可分段处理；视频文件需不超过2 GB，最多保留24张未保存候选照片。位于 iCloud 的视频可能需要系统下载，请检查网络及可用存储。

关闭页面会保留本机草稿，下次可继续；“丢弃”草稿会删除应用内导入副本，新视频导入成功会替换旧草稿，不删除相册原视频。如果保存被中断或结果待确认，请先检查系统相册，再按提示确认或重试，避免重复保存。

二、宠物吸引、滤镜与补光

声音、动画和主人录音怎么使用？

点击宠物吸引快捷按钮启动，长按可选择声音或动画。声音支持前后镜头，动画仅在前置镜头显示。声音可联动拍照、录像和实况，在吸引设置中可调整播放后的拍摄延迟和声音循环；录像模式启动声音吸引会联动开始录像，点击拍摄键结束。动画使用前置镜头并有启动倒计时，按页面提示使用；再次点按可停止吸引。

在“宠物吸引”的“主人原声”中录制、试听或删除声音，最多5条、每条10秒，录制需要麦克风权限。无声时检查设备音量、音频输出和播放状态；播放声也可能进入录像或实况音轨。

滤镜是否会影响录像和实况？

照片模式可实时预览宠物滤镜，并调节0–100%强度；保存普通照片时应用对应效果。生日、圣诞、新春、冬至和南瓜主题包含装饰效果。录像与实况不应用这些照片滤镜，选择“原片”可恢复普通照片原始效果。

前置和后置补光有什么区别？

前置镜头使用屏幕补光，可调颜色和亮度，并选择单色或双色；双色支持左右或上下分区、拖动分区比例及倾斜调整。可在取景框外的补光区域左右滑动切换预设色。iOS 17.2 及以上的前置拍摄页还支持音量键切换预设色。

后置镜头在设备支持时使用常亮灯或拍照闪光灯；录像使用常亮补光。部分镜头或设备不支持这些功能。请在录像开始前设置屏幕补光亮度，录制期间亮度锁定。离开相关拍摄状态时，应用恢复屏幕亮度设置。

三、权限、保存与常见问题

实况照片为什么不可用？

实况需要设备和镜头支持，并需要麦克风权限。开启实况后，前台准备会短时缓存快门前的声音，退出实况或进入后台后停止。拒绝麦克风时仍可普通拍照和录制无声视频，但无法使用实况。到系统“设置”中的本应用权限页面检查授权。

作品保存在哪里？保存失败怎么办？

成功保存的照片、视频、实况及提帧照片在系统相册中。保存需要“仅添加”权限；导入只处理您在系统选择器主动选中的视频，不扫描整个相册。

保存失败或结果待确认时，打开拍摄页的 ⓘ →“帮助与隐私”→“待保存作品”，按提示重试、确认或主动丢弃。先检查相册权限和可用空间；待保存队列达到限额时需先处理现有作品。删除应用及其数据前，请确认重要作品已保存。如果提示“尚未安全写入磁盘，请勿退出应用”，请保持应用开启，恢复存储条件后重试。

在哪里切换语言、重看教程？

打开 ⓘ →“帮助与隐私”，可重看新手教程及切换应用语言。支持简体中文、繁体中文、英语、日语、韩语和印度尼西亚语；选择“跟随系统”可恢复系统语言偏好。首次教程完成或跳过后不会每次启动自动出现。iPad 支持横竖屏、分屏与窗口大小适配。

发热或处理速度变慢怎么办？

长时间取景、录像及视频分析会增加能耗。暂停拍摄，让设备降温，检查剩余空间，缩短视频分析区间；系统可能限制后台处理，重新打开应用查看进度。避免在仍有未保存作品时删除应用。

四、隐私摘要

识别、滤镜和视频提帧在本机完成；应用不接入账号、广告、统计或媒体上传。录音、恢复作品、导入草稿及未完成提帧任务可能保留本地副本，并排除系统备份。系统相册与 iCloud 由您的系统设置管理。详见完整隐私政策。

五、联系我们

使用GitHub Issues 提交问题或建议，或先查看已有问题。提交需要 GitHub 账号；阅读本网站不需要登录。

请提供设备型号、iOS 或 iPadOS 版本、应用版本、出现问题的功能、操作步骤及提示的简短描述。应用版本可在“帮助与隐私”中查看。

请勿发送私人照片、视频、录音、完整日志、个人联系信息或凭据。公开反馈可被其他人看到；支持反馈不会自动读取您的设备数据。
