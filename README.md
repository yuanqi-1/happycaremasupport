# happycaremasupport

开心宠物相机的公开支持站点（GitHub Pages）：隐私政策与技术支持页面。

## 页面地址

- 落地页：<https://yuanqi-1.github.io/happycaremasupport/>
- 隐私政策（App Store Connect「Privacy Policy URL」）：<https://yuanqi-1.github.io/happycaremasupport/privacy.html>
- 技术支持（App Store Connect「Support URL」）：<https://yuanqi-1.github.io/happycaremasupport/support.html>

## 文件说明

| 文件 | 内容 |
|---|---|
| `index.html` | 落地页，两个入口链接 |
| `privacy.html` | 隐私政策（12 节，与 App 内隐私承诺口径一致） |
| `support.html` | 技术支持：FAQ、权限用途一览、联系方式 |

纯静态 HTML，无构建依赖，自适应手机与深色模式。

## 内容更新

文案源头在应用主仓库 `docs/上架合规/`。修改后直接编辑这里的 HTML 并推送，
GitHub Pages 约一分钟内自动更新。

## ⚠️ 提交 App Store 前必查

`support.html` 中的支持邮箱若仍为占位符 `support@example.com`，需替换为真实邮箱后
再在 App Store Connect 填写 Support URL。
