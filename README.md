## 技术支持 / Support

[GitHub Issues](https://github.com/yuanqi-1/happycaremasupport/issues) 提供问题反馈与建议入口。提交需账号，反馈公开可见；只提交不含个人信息的复现步骤与简短描述。
Use GitHub Issues for problems and suggestions. Submission requires an account and is public. Provide only non-sensitive reproduction steps and a brief description.

不要提交私人媒体、完整日志、设备标识、个人联系方式、凭据或源代码。页面中不得嵌入发布凭据、个人联系信息或设备数据。
Do not submit private media, full logs, device identifiers, personal contact details, credentials or source code. Never embed deployment credentials or private device data in these pages.
